Quick help

Help & controls

Every game page includes its own control instructions. These are the common controls used across the collection.

Desktop

Many games use arrow keys, WASD, Space, Enter or mouse clicks. The control guide appears directly below the game canvas.

Mobile

Games that support touch can be played with taps and swipes. Some games also show on-screen control buttons. For the best experience, rotate your device if the game area asks for a wider view.

Saving scores

Your high scores and saved favourites are stored in the browser on your current device. Clearing site data can remove them.

Game not responding?

Reload the page, check that JavaScript is enabled and use the Restart button. If the problem persists, report the title and device/browser to the site owner.
