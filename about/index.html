About Arcadia

A browser arcade for short, thoughtful and replayable game sessions.

Original browser game experiences

Arcadia is a collection of 100 original mini-game entries. The games use original JavaScript gameplay logic and custom SVG cover illustrations created for this project. The collection explores familiar genres such as racing, runners, puzzles, sports, memory, simulation and word games without embedding third-party game portals.

How progress works

Personal best scores, favourites and simple visit streaks are saved in your browser with local storage. They are not connected to a server account and will not automatically sync across devices.

Compatibility

Arcadia is designed for current browsers on desktop, tablet and mobile. Game controls vary by title and are described on each game page.
